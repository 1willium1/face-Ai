ระบบที่ 2: AI สแกนใบหน้า (Security AI Face Recognition)
============================================================
โฟลเดอร์: Security-System | รัน: http://localhost:5174


1. ที่มาของข้อมูล (สำคัญ)
----------------------------------------------------------------
ระบบ "ไม่ได้ดึงข้อมูลสด" จาก https://www.dusit.ac.th
รูปกิจกรรมทั้ง 168 รูปที่ใช้สแกน มาจาก URL ที่อยู่ในไฟล์
src/data/activities.ts (ชุดเดียวกับระบบ Gallery) ซึ่งสคริปต์
scripts/scrape_activities.js ขูดมา "ครั้งเดียวตอนสร้างโปรเจค"
แล้วแช่แข็งไว้

สิ่งเดียวที่วิ่งไป dusit.ac.th ตอนเปิดเว็บ = โหลด "ไฟล์รูป"
โดย browser ขอผ่าน /img-proxy (หลังบ้านฝั่งเราใน Vite)
ให้ไปโหลดไฟล์รูปมาแทน เพื่อเลี่ยง CORS แล้วค่อยวิเคราะห์
ใบหน้าในเครื่องเราเอง ไม่ได้ต่อ API/ฐานข้อมูลหลังบ้านเขา


2. โครงสร้าง
----------------------------------------------------------------
App -> Security -> SecurityScanner -> FaceCanvasOverlay (x168)
ข้อมูล: activities.ts (static, ชุดเดียวกับ Gallery)
หลังบ้านของเรา: /img-proxy (ใช้งานได้)
                + Python :8000 (ยังพังอยู่ ขาดโฟลเดอร์ scanner/)


3. แต่ละไฟล์ทำอะไร
----------------------------------------------------------------
src/App.tsx / main.tsx ... เปิดหน้า Security ตรงๆ (ไม่มี router แล้ว)
src/pages/Security.tsx ... หน้า AI: สถิติ + ปุ่มหน้าแรก
src/components/SecurityScanner.tsx . อัปโหลดรูปเป้าหมาย ตั้งชื่อ สไลเดอร์ threshold
                                ช่องค้นหา/กรองปี แล้ววนสร้าง FaceCanvasOverlay
                                ทีละรูป (168 รูป)
src/components/FaceCanvasOverlay.tsx . หัวใจระบบ: ลอง backend 2 ชั้น (ปิดอยู่)
                                -> ตกมา browser AI: หาใบหน้า (tiny)
                                -> สกัดลายเซ็นใบหน้า (landmark+recognition)
                                -> เทียบกับรูปเป้าหมาย (ห่าง <= 0.55 = คนเดียวกัน)
                                -> วาดกรอบเขียว/แดง + นับคน + จำผลลง cache
src/components/DetailModal.tsx . ดูรูปใหญ่เมื่อคลิกภาพ
src/utils/faceDetectionQueue.ts . คิวจำกัดสแกนพร้อมกันทีละ 3 รูป กันเครื่องค้าง
public/models/ ........... สมอง AI 3 ก้อน: tiny (หาหน้า) + landmark (68 จุด)
                                + recognition (ลายเซ็นหน้า)
vite.config.ts ........... port 5174 + /img-proxy (หลังบ้านตัวจริง:
                                ไปโหลดรูปแทน browser เลี่ยง CORS)
backend/main.py .......... เซิร์ฟเวอร์ Python (FastAPI) จำใบหน้าฝั่ง server
                                **ตอนนี้รันไม่ได้ ขาดโฟลเดอร์ scanner/**
backend/face_registry.py . ที่เก็บลายเซ็นใบหน้าคนที่ลงทะเบียน (JSON)
backend/train_faces.py ... สคริปต์สอนหน้าเป้าหมาย


4. วิธีใช้งาน
----------------------------------------------------------------
cd "C:\Users\LEGION\Desktop\มี2งาน\Security-System" แล้ว npm run dev
1. เปิด http://localhost:5174 ใส่ URL แหล่งข้อมูล กดเริ่มสแกน
2. ตั้งรูปเป้าหมาย: อัปโหลด (ใช้รูปหน้าตรงชัดๆ) หรือกดใช้รูปตัวอย่าง +
   ตั้งชื่อ (หาใครก็ได้ ไม่ผูกกับ ดร.วิชชา)
3. ปรับสไลเดอร์ threshold / ค้นหา / กรองปี เพื่อลดจำนวนรูป
   (สแกนครั้งแรก 168 รูปใช้เวลาหลายนาที รอบถัดไปมี cache เร็วขึ้น)
4. อ่านผล: กรอบเขียว = ใช่เป้าหมาย (+ชื่อ +%) / กรอบแดง = คนอื่น /
   ป้ายเหลือง = นับได้อย่างเดียวจำตัวตนไม่ได้
   หมายเหตุสเกล %: 50+ ถือว่าตรงแล้ว (0.3->70%, 0.4->60%, 0.5->50%)
5. คลิกภาพ -> ดูภาพขยายพร้อมวงกลมพิกัด
